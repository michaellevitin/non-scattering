# non-scattering
Scripts accompanying the paper  [*A family of homogeneous convex non-scattering domains with analytic non-circular boundaries*](https://michaellevitin.net/papers.html#non-scattering) by [Fioralba Cakoni](https://sites.math.rutgers.edu/~fc292) and [Michael Levitin](https://www.michaellevitin.net)
### Files: 
* Python script, written by Claude [nonscattering_branch.py](nonscattering_branch.py)
* Mathematica .wl package  [nonscattering_branch.wl](nonscattering_branch.wl)
* Main Mathematica notebook [run_nonscattering.nb](run_nonscattering.nb)
* Output of the computations as .csv file [nonscattering_branch.csv](nonscattering_branch.csv)
